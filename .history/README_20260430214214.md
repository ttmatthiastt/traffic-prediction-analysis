# Traffic Prediction Project

## Overview
This project focuses on forecasting short-term traffic at an intersection using historical sensor data.  
The goal is to predict the **next time-step total traffic** based on recent observations and time-related features.

## Dataset
The dataset contains timestamped traffic counts collected from a fixed sensor.  
Features used include:
- Total traffic count
- Time of day
- Day of week

## Approach

### Feature Engineering
- Extracted hour of day and day of week from timestamps
- Added a weekend indicator
- Created lag features (t-1, t-2, t-3) to capture temporal dependencies

### Modeling
Used a chronological split (no shuffling):
- 80% training / 20% testing

Models compared:
- **Naive baseline** (predicts next = current)
- **Linear Regression**
- **Random Forest Regressor**

## Results

| Model              | MAE   | RMSE  |
|-------------------|------|------|
| Baseline          | 27.64 | 38.60 |
| Linear Regression | 25.66 | 34.23 |
| Random Forest     | 19.50 | 26.81 |

The Random Forest model performed best, capturing daily traffic patterns such as:
- Low nighttime traffic
- Morning increase
- Midday stabilization

However, it smooths sudden spikes, likely due to limited lag features and model averaging.
